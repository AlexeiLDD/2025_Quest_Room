# 2025_Quest_Room

# VR-проект «Симулятор Квест-комнаты»

Учебный проект по дисциплине «Разработка приложений на языке C#» (Unity)  
(МГТУ им. Н. Э. Баумана, кафедра «Компьютерные системы и сети»).  

Цель проекта — разработка VR-симулятора квест-комнаты с интерактивным окружением, ориентированного на решение последовательных логических и предметных задач в условиях полного погружения.

---

## Основная идея

Основная идея проекта заключается в создании виртуальной квест-комнаты, в которой пользователь, находясь в VR-пространстве, последовательно решает набор взаимосвязанных задач для продвижения по сценарию.

Игровое окружение выступает не только в роли визуального пространства, но и является активной частью игрового процесса: объекты могут взаимодействовать с пользователем, реагировать на действия и использоваться для решения головоломок.

Проект ориентирован на демонстрацию возможностей VR-технологий для создания иммерсивных интерактивных сценариев и игровых механик.

---

## Ключевые механики

- Свободное перемещение в VR от первого лица  
- Взаимодействие с объектами (захват, активация, использование)  
- Последовательная система задач  
- Визуальная и звуковая обратная связь

## Запуск проекта

1. Установить Unity 2022 LTS  
2. Открыть проект через Unity Hub  
3. Включить OpenXR  
4. Запустить сцену MainQuestRoom
